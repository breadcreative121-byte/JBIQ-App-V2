How the Home ↔ Spaces navigation works

  • Home stays the front door — a no-scroll voice screen. Spaces is a second surface, never the first thing you land on.
  • Swipe left (or tap Spaces →) moves through one horizontal track: Home → Astrology → Devotion → Health → Career → Your Friend → News. The page dots show where you are.
  • Inside Spaces, the top tab strip jumps straight to any vertical, and ‹ returns Home. The swipe is an accelerator — never the only way in (matters for first-timers).
  • Each Space is one hero widget + a few actions, following the same Context Line → result → actions anatomy. It’s widgets and actions, not a content feed.
  • The mic bar persists on every panel — every widget label is a thing you can also just say.
  • Moment-led Home deep-links: a live moment (darshan, news brief, rashifal) leads Home; its one action jumps into that vertical’s Space and flashes the relevant widget — and the tab strip’s ‹ breadcrumb (e.g. “‹ Diwali darshan”) returns you to that exact moment.
